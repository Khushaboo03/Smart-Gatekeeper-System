# Smart Gatekeeper System 🚗🔐

An intelligent security-based vehicle authentication system that uses Artificial Intelligence, Computer Vision, and Deep Learning to automate vehicle monitoring, authentication, and surveillance in real time.

The project is designed to enhance smart security systems by detecting vehicles, identifying authorized entries, and monitoring suspicious activities using AI-powered detection models.

---

## 📌 Features

- 🚘 Real-time Vehicle Detection
- 🔍 Vehicle Authentication & Verification
- 🎥 Smart Security Monitoring
- 🧠 YOLOv8-based Object Detection
- 📷 Live Camera Surveillance
- 🔐 Admin Login Authentication
- 📊 Detection Result Visualization
- ⚡ Fast and Accurate Detection
- 🖥️ User-Friendly Web Interface

## 🧠 System Workflow

1. Capture vehicle image/video from camera.
2. Process frames using OpenCV.
3. Detect vehicles using YOLOv8 model.
4. Authenticate vehicle details.
5. Display monitoring results on dashboard.
6. Alert admin for unauthorized vehicles.
